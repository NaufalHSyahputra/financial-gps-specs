# V1 acceptance scenario catalog

**Status:** Draft examples for review and future automated golden tests; not executed and not a substitute for the normative requirements. Amounts are IDR. Each case assumes valid configuration and complete history unless stated. Scenario references are links to source documents via [traceability](traceability.md); where a scenario does not cover every clause, that remains a gap.

## Review and expansion

Each case requires domain and product review before becoming a test oracle. Add explicit cases for account validation, time zones, failures, refund and recategorization, recurring stage boundaries, statement/cutoff changes, installment schedules, restore, accessibility and platform behavior. Use exact engine rules for rounding and dates; do not infer them from examples. Traceability cells that say **gap** are not covered merely because a related case exists.
